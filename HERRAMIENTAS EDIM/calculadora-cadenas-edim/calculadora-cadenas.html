Formulas Aplicadas
Longitud de Cadena (pasos)
Lp = 2Cp + (N1+N2)/2 + [(N2-N1)/(2pi)]^2 / Cp
Velocidad de Cadena
v = p * N1 * n / (60 * 1000) [m/s]
Potencia de Diseno Corregida
Pd = P * Ks [kW]
Fuerza de Traccion
F = 1020 * P / v [N]
Notas Tecnicas
  • Numero minimo de dientes pinon: 11 (recomendado >= 17 para velocidades altas)
  • Relacion maxima de transmision recomendada: i <= 7
  • Distancia entre centros recomendada: 30p a 50p (optimo)
  • Angulo de contacto pinon: >= 120 grados
  • Longitud de cadena debe ser numero entero de pasos (ajustar centros si es necesario)
  • Para cadenas multiplex, multiplicar potencia por factor de hilera (1.7 para duplex, 2.5 para triplex)
