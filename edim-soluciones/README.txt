EDIM SOLUCIONES - Sitio Web Corporativo
========================================

Estructura del proyecto:
------------------------
edim-soluciones/
|-- index.php          # Pagina principal
|-- contact.php        # Procesamiento de formulario
|-- css/
|   |-- style.css      # Estilos completos (Neumorphism + Gradientes)
|-- js/
|   |-- main.js        # JavaScript vanilla (smooth scroll, animaciones, validacion)
|-- assets/
|   |-- img/
|   |   |-- logo-edim-png.png   # Logo de la empresa
|-- includes/          # Carpeta para includes PHP futuros

Instrucciones:
--------------
1. Coloca tu logo en: assets/img/logo-edim-png.png
2. Sube todos los archivos a tu servidor web con soporte PHP
3. Accede a index.php desde tu navegador

Fuentes utilizadas (Google Fonts):
----------------------------------
- Orbitron: Titulos y display (futurista)
- Rajdhani: Texto tecnico y navegacion
- Space Grotesk: Cuerpo de texto

Caracteristicas:
----------------
- Diseno Neumorphism (Soft UI)
- Gradientes en botones, titulos y elementos decorativos
- Header sticky con glassmorphism
- Smooth scrolling
- Scroll reveal animations
- Contadores animados
- Slider de testimonios automatico
- Formulario con validacion JavaScript
- Totalmente responsive
- SEO optimizado (Schema.org, Open Graph, Twitter Cards)
- Sin emojis - Iconografia SVG profesional
